Built-in agents내장 에이전트

An agent that knows every button.모든 버튼을 아는 에이전트.

Every action in App Manager is also a tool. Open a Claude Code or Codex session for any app with one click, and it can do whatever you can: write store copy in every language, render screenshots, wire signing, read a crash report and fix it. Each setup screen has an Ask Your Agent button that hands the step over with exact instructions.

App Manager의 모든 기능은 에이전트가 쓰는 도구이기도 합니다. 앱마다 클릭 한 번으로 Claude Code나 Codex 세션을 열면, 여러 언어의 스토어 문구 작성, 스크린샷 제작, 서명 연결, 크래시 분석과 수정까지 사람이 할 수 있는 일은 에이전트도 할 수 있습니다. 설정 화면마다 있는 에이전트에게 묻기 버튼은 그 단계를 정확한 안내와 함께 넘겨 줍니다.

  • Its own device, every session.세션마다 전용 기기. A device pool hands each session an emulator of its own (and an iOS simulator on the Mac), so two agents never fight over one. 디바이스 풀이 세션마다 전용 에뮬레이터(Mac에서는 iOS 시뮬레이터도)를 배정해, 두 에이전트가 한 기기를 두고 다투지 않습니다.
  • Guardrails on.안전장치 기본 탑재. Anything destructive shows a preview and waits for a confirm; dry runs are the default. 되돌릴 수 없는 작업은 미리 보기를 보여 주고 확인을 기다립니다. 기본은 시험 실행입니다.
  • Bring your own client.원하는 클라이언트로. The same tools are an MCP server and a CLI (am), for Claude Desktop or a terminal. 같은 도구를 MCP 서버와 CLI(am)로도 제공해 Claude Desktop이나 터미널에서 쓸 수 있습니다.

Do I need a Mac?Mac이 꼭 필요한가요?

Only for iOS. The Windows version covers the whole Google Play side: listings, screenshots, Play questionnaires, signing, deploys, reviews, analytics, agent sessions and emulators. Building for iOS and publishing to the App Store need the Mac version.

iOS에만 필요합니다. Windows 버전은 등록정보, 스크린샷, Play 설문, 서명, 배포, 리뷰, 분석, 에이전트 세션, 에뮬레이터까지 Google Play 쪽 전부를 다룹니다. iOS 빌드와 App Store 출시에는 Mac 버전이 필요합니다.

Which projects does it work with?어떤 프로젝트를 지원하나요?

Flutter apps, and native Android projects. Point App Manager at the folder that holds them and each one shows up with its live Google Play and App Store status.

Flutter 앱과 네이티브 Android 프로젝트입니다. 프로젝트가 들어 있는 폴더를 지정하면 각 앱이 Google Play·App Store의 현재 상태와 함께 나타납니다.

Do I need Claude Code or Codex?Claude Code나 Codex가 있어야 하나요?

Only for the agent actions. They are on the list of tools App Manager drives, next to Flutter, Android Studio and Xcode. The first launch checks what's installed, and Doctor shows anything missing with a link to fix it.

에이전트 기능에만 필요합니다. Flutter, Android Studio, Xcode처럼 App Manager가 움직이는 도구 중 하나입니다. 첫 실행 때 설치된 도구를 확인하고, 진단 화면이 빠진 것을 해결 링크와 함께 보여 줍니다.

Why does it need an account?왜 계정이 필요한가요?

App Manager is in early access, and each new account is switched on by hand. Create one in the app; it unlocks by itself as soon as it's approved, with no restart. Once signed in, it keeps working offline for at least 7 days.

App Manager는 얼리 액세스 중이며, 새 계정은 개발자가 직접 승인합니다. 앱에서 계정을 만들면 승인되는 즉시 다시 시작하지 않아도 저절로 열립니다. 한 번 로그인하면 오프라인에서도 최소 7일 동안 그대로 쓸 수 있습니다.

What leaves my computer?어떤 정보가 컴퓨터 밖으로 나가나요?

Only what the services you connect need: Google Play, App Store Connect, Firebase and Google Analytics, AdMob, GitHub Pages. There is no telemetry, and key files stay where you keep them. The sign-in check sends your email, the computer's name and the app and OS versions every few minutes.

직접 연결한 서비스(Google Play, App Store Connect, Firebase·Google Analytics, AdMob, GitHub Pages)에 필요한 것만 나갑니다. 사용 데이터 수집은 없고, 키 파일은 원래 위치에 그대로 둡니다. 로그인 확인 때는 이메일, 컴퓨터 이름, 앱·OS 버전을 몇 분마다 보냅니다.

Is the download safe to open?다운로드한 파일은 안전한가요?
