Privacy Policy for Rex Shorts Uploader

Effective date: 2026-11-20

Rex Shorts Uploader (“the tool”) is a private command-line tool by Rexyrex. It uploads the videos of Rexyrex’s own channels, Rexy’s AI Daily and One More Split, to those channels’ own TikTok accounts as drafts. It runs only on its developer’s own computer, is not offered to the public, and has no users other than its developer.

1. What the tool accesses

  • TikTok account details (user.info.basic). With the account owner’s permission, the tool reads the signed-in account’s ID (open ID) and display name, only to confirm which account it is uploading to.

  • Video upload (video.upload). With the account owner’s permission, the tool uploads the owner’s own video files to that account’s TikTok inbox as drafts. It does not post, edit or delete anything on the account.

The tool does not read, collect or store data about anyone else: no viewers, followers, comments, messages or analytics.

2. Where data is stored

The sign-in tokens that TikTok issues to the tool, and the account ID and display name, are stored only on the developer’s computer, in a folder readable by that user alone. Uploaded videos are the developer’s own content. Nothing is sent to any server other than TikTok’s own API, and nothing is sold or shared.

3. Revoking access

Access can be removed at any time by removing the tool from the TikTok account’s list of connected apps in TikTok’s security settings. Deleting the token file on the computer also ends the tool’s access.

4. Changes to this policy

If this policy changes, the effective date above will be updated.
