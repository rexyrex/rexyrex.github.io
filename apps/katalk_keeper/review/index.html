슬쩍 — permission demonstration

Release 1.0.0 (1), com.rexyrex.katalk_keeper. This recording demonstrates the optional accessibility disclosure and affirmative consent, Android permission settings, local archive UI with explicitly labelled test messages, and the ongoing foreground-service notification. The messages are synthetic samples entered by the app’s built-in test action. This is not a recording of live KakaoTalk message capture.

Accessibility reads KakaoTalk chat-screen text to archive messages and detect deletion placeholders. It does not click, type, send messages, or access other apps. All stored content stays on device. Notification access provides background capture; the optional specialUse foreground service maintains the listener and shows an ongoing notification.
