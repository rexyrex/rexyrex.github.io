1. 기기에서 처리하는 정보 슬쩍은 사용자가 허용한 알림 접근 권한으로 카카오톡 알림에 포함된 메시지, 보낸 사람, 대화방 이름, 시각, 프로필 사진을 읽어 보관합니다. 사진 보관을 켜면 알림에 실제 포함된 사진도 저장합니다. 알림에 없는 사진이나 설치 전 메시지는 복원하지 못합니다.

선택 사항인 화면 수집은 Android 접근성 서비스 API로 카카오톡 대화 화면의 메시지, 보낸 사람, 대화방 이름, 시각과 삭제 표시를 읽어 보관하고 삭제 여부를 감지합니다. 다른 앱을 조작하거나 메시지를 대신 보내지 않습니다. 동의하지 않아도 알림 보관 기능을 이용할 수 있습니다.

2. 이용 목적과 저장 위치 정보는 사용자의 개인 메시지 보관함, 검색, 대화방별 표시와 삭제된 메시지 확인에 사용합니다. 허용 후에는 앱 화면을 닫아도 알림 수집이 계속됩니다. 모든 기록과 설정은 이 기기의 앱 저장 공간에 보관하며 개발자 서버로 전송하거나 제3자에게 공유하지 않습니다. 앱의 클라우드 백업 및 기기 전송 대상에서 보관 데이터를 제외합니다.

3. 광고·분석·계정 앱은 회원가입, 광고, 분석 SDK 또는 외부 추적 기능을 사용하지 않습니다. 위치, 연락처 목록, 마이크나 카메라 권한을 요청하지 않습니다.

4. 보관 기간과 삭제 기록은 사용자가 삭제하거나 앱을 제거할 때까지 보관합니다. 슬쩍의 설정 > 모든 기록 삭제에서 보관한 대화, 메시지 및 첨부 이미지를 삭제할 수 있습니다. Android 설정에서 앱 저장 공간을 지우거나 앱을 제거해도 기록이 삭제됩니다. 개발자는 기기 안의 기록에 접근할 수 없어 원격 삭제나 복원을 제공하지 않습니다.

6. 이용 대상과 관계 슬쩍은 성인 사용자가 자신의 기기에 표시된 대화를 개인적으로 보관하기 위한 앱입니다. 다른 사람의 기기를 몰래 감시하는 용도로 사용하지 마세요. 슬쩍은 Kakao Corp.의 공식 앱이 아니며 제휴 관계가 없습니다.
