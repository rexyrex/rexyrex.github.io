RexDesk Your Mac, from anywhere. 어디서든, 내 Mac 그대로.

Control a Mac from another Mac as if you were sitting at it. Hardware video on both ends keeps text sharp and the pointer immediate, on your own network or across the internet, end-to-end encrypted.

다른 Mac에서, 바로 앞에 앉은 것처럼 Mac을 제어하세요. 양쪽 모두 하드웨어로 영상을 처리해 글자는 선명하고 포인터는 즉시 따라옵니다. 같은 네트워크에서도, 인터넷 너머에서도, 종단 간 암호화로.

Set up설정

Three steps, about a minute.세 단계, 1분이면 됩니다.

  1. 1

    On the Mac you want to reach접속할 Mac에서

    Open RexDesk Host. It lives in the menu bar, asks once for Screen Recording and Accessibility, and lets you set an access password for when nobody is at that Mac.

    RexDesk Host를 엽니다. 메뉴 막대에 자리 잡고, 화면 기록과 손쉬운 사용 권한을 한 번 묻습니다. 그 Mac 앞에 아무도 없을 때를 위한 접속 암호도 정해 두세요.

  2. 2

    On the Mac in front of you내 앞의 Mac에서

    Open RexDesk. Macs on the same network appear by themselves. The first time, check that the fingerprint matches the one in the host's menu, then type the password.

    RexDesk를 엽니다. 같은 네트워크의 Mac은 저절로 나타납니다. 처음 연결할 때는 지문이 Host 메뉴의 지문과 같은지 확인한 뒤 암호를 입력하세요.

  3. 3

    From anywhere else다른 곳에서는

    Copy the Host ID from the host's menu and paste it into “Connect to”. A Mac you have connected to once on the same network needs nothing at all.

    Host 메뉴에서 Host ID를 복사해 “Connect to”에 붙여 넣으세요. 같은 네트워크에서 한 번 연결해 둔 Mac은 그것도 필요 없습니다.

Bad Wi-Fi불안정한 Wi-Fi

Packets get lost. The picture doesn't.패킷은 사라져도, 화면은 그대로.

Each frame travels over UDP as a handful of pieces plus a few spares. Lose some and the viewer rebuilds the frame from what arrived; lose too many and it asks again for only what is missing. The number of spares follows the network, from 5% up to 50%.

한 프레임은 UDP 위에서 여러 조각과 예비 조각 몇 개로 나뉘어 갑니다. 일부가 사라지면 도착한 조각으로 프레임을 복원하고, 너무 많이 사라지면 빠진 조각만 다시 요청합니다. 예비 조각의 비율은 네트워크 상태에 따라 5%에서 50%까지 달라집니다.

Security and privacy보안과 개인정보

Only your two Macs can read it.내 Mac 두 대만 읽을 수 있습니다.

Encrypted end to end종단 간 암호화

Every connection starts with a P-256 key exchange that the host signs with its own identity key, then runs under AES-256-GCM in both directions.

모든 연결은 Host가 자신의 신원 키로 서명한 P-256 키 교환으로 시작하고, 이후 양방향 모두 AES-256-GCM으로 보호됩니다.

A host you can recognise알아볼 수 있는 Host

The viewer remembers each host's fingerprint the first time and refuses one that has changed.

RexDesk는 처음 연결할 때 Host의 지문을 기억하고, 지문이 달라진 Host는 거부합니다.

The password stays home암호는 밖으로 나가지 않습니다

The access password never crosses the wire: the viewer proves it knows it with a code bound to that one session. Wrong guesses are rate-limited.

접속 암호는 네트워크로 전송되지 않습니다. 해당 세션에만 유효한 코드로 암호를 알고 있음을 증명합니다. 틀린 시도는 횟수가 제한됩니다.

Over the internet인터넷을 통할 때

A small rendezvous service introduces the two Macs, which then open a direct path to each other. Where a network blocks that, the service relays the connection, still encrypted. It never sees the screen and stores nothing, and its address is a setting in both apps.

작은 중개 서비스가 두 Mac을 서로 소개하면, 둘은 직접 통신 경로를 엽니다. 네트워크가 이를 막으면 서비스가 암호화된 상태 그대로 연결을 중계합니다. 서비스는 화면을 볼 수 없고 아무것도 저장하지 않으며, 그 주소는 두 앱의 설정에서 바꿀 수 있습니다.

No account, no sign-up. Each device keeps its own identity key, and a new device over the internet always needs the access password.

계정도 가입도 없습니다. 각 기기는 자신의 신원 키를 기기 안에 보관하며, 인터넷을 통한 새 기기의 접속에는 항상 접속 암호가 필요합니다.

FAQ

Questions, answered.자주 묻는 질문.

Which app goes on which Mac?어느 앱을 어느 Mac에 설치하나요?

RexDesk Host goes on the Mac you want to reach and stays running in its menu bar. RexDesk goes on the Mac you are using. A Mac can have both.

RexDesk Host는 접속하려는 Mac에 설치해 메뉴 막대에 켜 둡니다. RexDesk는 지금 사용하는 Mac에 설치합니다. 한 Mac에 둘 다 설치해도 됩니다.

Can I connect without installing anything?아무것도 설치하지 않고 접속할 수 있나요?

On the device you are holding, yes: RexDesk in the browser is made for a current Chrome or Edge and is encrypted end to end like the apps. Safari has had only a little testing, Firefox none. The Mac you reach still needs RexDesk Host.

지금 쓰는 기기에는 필요 없습니다. 브라우저용 RexDesk는 최신 Chrome이나 Edge에 맞춰 만들었고, 앱과 똑같이 종단 간 암호화됩니다. Safari는 조금만 테스트했고 Firefox는 아직 테스트하지 않았습니다. 접속할 Mac에는 RexDesk Host가 필요합니다.

Do both Macs have to be on the same network?두 Mac이 같은 네트워크에 있어야 하나요?

No. On the same network they find each other. From anywhere else, paste the Host ID from the host's menu, or add the Mac by address if you use Tailscale or another VPN.

아니요. 같은 네트워크에서는 서로를 자동으로 찾습니다. 다른 곳에서는 Host 메뉴의 Host ID를 붙여 넣거나, Tailscale 같은 VPN을 쓴다면 주소로 Mac을 추가하세요.

Is there an account, or a subscription?계정이나 구독이 필요한가요?

Neither. There is nothing to sign up for: a host is identified by its own key, and you get in with the access password you set on it.

둘 다 없습니다. 가입할 것이 없습니다. Host는 자신의 키로 식별되고, 그 Mac에 정해 둔 접속 암호로 들어갑니다.

Why does the host ask for Screen Recording and Accessibility?Host는 왜 화면 기록과 손쉬운 사용 권한을 요청하나요?

macOS guards both. Screen Recording lets RexDesk Host capture the display to send it; Accessibility lets it move the pointer and type what you type. You grant each once, in System Settings.

둘 다 macOS가 보호하는 기능입니다. 화면 기록은 보낼 화면을 캡처하는 데, 손쉬운 사용은 포인터를 움직이고 입력을 대신하는 데 필요합니다. 시스템 설정에서 각각 한 번만 허용하면 됩니다.

What if nobody set a password?암호를 정해 두지 않았다면요?

On the same network a new device can still ask, and someone at that Mac clicks Allow. Over the internet a new device always needs the access password.

같은 네트워크에서는 새 기기가 접속을 요청할 수 있고, 그 Mac 앞에 있는 사람이 허용을 누르면 됩니다. 인터넷을 통한 새 기기의 접속에는 항상 접속 암호가 필요합니다.

Does it work on Intel Macs?Intel Mac에서도 되나요?

Yes, both apps run on Apple silicon and Intel with macOS 14 or later. The full-colour 4:4:4 mode needs an Apple-silicon Mac on the viewing side.

네. 두 앱 모두 macOS 14 이상의 Apple 실리콘과 Intel Mac에서 동작합니다. 풀컬러 4:4:4 모드는 보는 쪽이 Apple 실리콘 Mac이어야 합니다.
