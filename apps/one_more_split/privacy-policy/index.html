Privacy Policy for the One More Split uploader

Effective date: 2026-11-19

The One More Split uploader (“the tool”) is a private command-line tool by Rexyrex. It publishes the physics-simulation videos of the One More Split channel to YouTube and Instagram. It runs only on its developer’s own computer, is not offered to the public, and has no users other than its developer.

1. What the tool accesses

  • YouTube (YouTube Data API). With the account owner’s permission, the tool uploads videos to the owner’s own channel and reads that channel’s basic details (its name and ID) to confirm which channel it is signed in to.

  • Instagram (Instagram Graph API). With the account owner’s permission, the tool publishes Reels to the owner’s own Instagram professional account and reads that account’s ID and username.

The tool does not read, collect or store data about anyone else: no viewers, followers, comments, messages or analytics.

2. Where data is stored

The sign-in tokens that Google and Meta issue to the tool are stored only on the developer’s computer, in a folder readable by that user alone. Uploaded videos, titles and captions are the developer’s own content. Nothing is sent to any server other than Google’s and Meta’s own APIs, and nothing is sold or shared.

3. Google user data

The tool’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Revoking access

Access can be removed at any time from Google account permissions or from Instagram’s and Facebook’s “Apps and websites” settings. Deleting the token files on the computer also ends the tool’s access.

5. Changes to this policy

If this policy changes, the effective date above will be updated.
