# rexyrex.github.io

Personal GitHub Pages site for [rexyrex](https://github.com/rexyrex) — portfolio, games, music, and the privacy-policy / support pages for published mobile apps.

## Pages

| Path | What it is |
|---|---|
| `/` | Landing page (Bootstrap 5, vanilla JS animations) |
| `/typing/` | Typing speed game — Korean / English / programmer modes, Firebase leaderboards (jQuery + Bootstrap 4.6 + Firebase compat 8) |
| `/deadlyBalloons/` | Landing page for the Deadly Balloons desktop game (dependency-free) |
| `/music/showcase.html` | Music showcase with SoundCloud embeds |
| `/animation.html` | CSS animation showcase built on Vue 3 |
| `/parser/` | KakaoParser companion pages: admin tools (query/download) + Korean help & ToS docs |
| `/support/` | App store support/contact page (fully standalone) |
| `/apps/` | **Generated** privacy-policy pages — see below |
| `/smartthings-callback.html` | OAuth hand-off shim for the Project Manager app — do not modify |

## Shared navbar

`navbar.html` is a pure HTML **fragment** (not a standalone page). `/js/common.js` fetches it into `<div id="nav-placeholder">` on every page, injects `/css/navbar.css` + Font Awesome if the host page lacks them, and wires up the dropdown/toggler behavior in vanilla JS. It works with or without jQuery on the host page.

Because the navbar is fetched at runtime, pages must be served over HTTP — `file://` won't show it:

```
python3 -m http.server 8000
```

## Generated pages — do not hand-edit

`apps/index.html` and every `apps/<app_id>/privacy-policy/index.html` are generated by the external **App Manager** tool, which rewrites `apps/index.html` wholesale on each run (display names are parsed from each page's `<title>` after the ` — ` separator). Style them only via the `main.privacy-article` / `.privacy-meta` / `ul.apps-index` rules in `/css/index.css`.

### Frozen URL contract (referenced by live app-store listings and tools)

- `/apps/` and `/apps/<app_id>/privacy-policy/`
- `/support/`
- `/app-ads.txt`
- `/css/index.css`, `/js/common.js`, `/navbar.html`, `/favicon.ico`
- `/smartthings-callback.html`

## Dependencies (CDN, pinned + SRI)

- Bootstrap 5.3.8 (main pages) / Bootstrap 4.6.2 + Popper 1.16.1 (typing game only)
- jQuery 3.7.1 (typing game + parser tools only)
- Vue 3.5 (animation showcase)
- Font Awesome 6.7.2, Google Fonts (Inter, JetBrains Mono)
- Firebase compat 8.2.8 + moment 2.24.0 (typing game, parser tools)
